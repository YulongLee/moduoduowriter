# 搜索表现监测

## 首次接入

由域名所有者在 Google Search Console、百度搜索资源平台及 Bing Webmaster Tools 添加站点，并按各平台当前提供的 TXT、文件或页面标签完成验证。验证代码尚未提供，不伪造验证标签。已有域名解析和邮件配置应保留。

验证后提交上述 sitemap，检查首页和 6 个说明页：请求成功、规范 URL 正确、允许索引、抓取正文可见。IndexNow 通知并不代替所有权验证、Google/百度站长提交或索引检查。

## 建议监测

- 每周查看：被发现/已抓取/已索引 URL、排除原因、404、canonical 冲突。
- 有数据后比较：曝光、点击、CTR、品牌与功能词、登录入口转化。
- AI 引荐：仅在取得真实分析或日志数据后，区分 ChatGPT、Perplexity、Bing/Copilot 等来源。没有数据时标记未知。
- 不对聊天模型进行批量刷问，不制造评价、引用、外链或用户规模。
- 更新功能时同步内容页、llms 摘要与 sitemap；保留真实更新日期。新页面先保证有独立内容，再加入公开路径与 sitemap。

本任务没有设置定时任务或外部分析脚本。
