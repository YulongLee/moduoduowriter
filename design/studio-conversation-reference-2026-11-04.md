# 创作对话：三栏工作台

根据用户提供的参考图重做登录后的 `#conversation` 页面，原有品牌图标、墨绿主导航和手动收起行为保留。

- 左侧显示当前账号的真实会话，按北京时间分为今天、昨天、更早。记录缺失时间时不编造日期；标题与实际消息摘要用于识别对话。
- 中间为当前会话、消息和底部输入区。消息独立滚动，输入区保留在工作区底部；小屏通过可收起的历史与工具面板使用。
- 窗口高度不超过 480px 时，中央区域改为整体滚动，资料与设置面板在输入区内展开，避免手机横屏或软键盘占用空间后裁切发送操作。
- 支持会话重命名、明确确认后删除、TXT 导出、新建、关联作品与历史切换。改名保留已有消息、请求编号和作品引用，不启动生成；未发送会话的自定义名称在首轮发送后仍保留。
- 对话回复按实际文本展示标题、列表、引用、表格、加粗及代码。通过 React 元素渲染，原始 HTML 和链接保留为文字，不执行脚本、不加载回复中的外链图片，也不编造书籍或人物卡。
- 右侧工具箱分为创作辅助、内容优化、素材灵感，连接现有八个工具。关联作品和当前输入可带入工具，使用前仍需用户显式提交；世界观建议只填入输入框，已有草稿时先确认替换。
- 原有多轮历史、引用移除、输入法防误发送、停止、任务状态恢复、显式重试、用量预估与账本处理继续使用同一控制器。
- 关联作品移除时，停止正在接收的任务；禁止发送、恢复和重试旧作品请求，防止失效引用被继续使用。切换账号保持独立记录和草稿。
- 页面不显示实际模型名称，不提供未接通的联网、分享或深度思考按钮。公开首页的登录意图只预填聊天输入，不自动生成或计费。

浏览器已保存的权限规则仍限制自动目测。组件、接口、安全渲染、对比度和构建检查不替代视觉验收。
