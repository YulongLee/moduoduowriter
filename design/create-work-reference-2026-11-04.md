# 新建作品：独立创建页面

参考用户提供的双栏新建作品设计，将原有弹窗替换为登录后的 `#create` 页面，沿用现有品牌图标、墨绿侧栏和山水视觉。

- 左侧填写作品名称（必填，最多 50 字）、简介（可选，最多 500 字）、作品类型、题材和最多三项风格。名称和简介显示实时计数。
- 提供现有可实际创作的长篇小说、短篇故事和文字剧本三种类型，题材与风格可通过「更多」选择。
- 右侧四个原创模板为玄幻修仙、都市异能、科幻未来和历史权谋，填入可编辑的大纲、人物和世界框架。模板不会生成章节正文或调用模型。
- 切换模板只更新仍然保持模板默认值的内容，作者手改的名称、简介与规划保留。旧入口携带的长想法保存完整资料，不因简介字数限制丢失。
- 已带入的创作框架可在创建前展开查看、修改；超过资料长度限制时提供直接整理的入口，保留原文直至作者自行修改。
- 全站原有新建按钮和侧栏入口进入统一页面，保留长篇／短篇／剧本等预选类型。取消或返回回到安全的来源页面，不创建作品。
- 草稿在当前账号的页面切换中保留，切换账号后不继承，未提交的创建草稿不写入通用浏览器存储。
- 「AI 帮我构思」显式打开已有规划流程，带入当前名称、题材、风格、大纲和人物；不自动生成、不自动计费。关闭规划后仍可回到当前创建草稿。
- 普通创建保存实际填写和模板字段，进入编辑器时正文为空。AI 规划流程仍支持作者自行编辑和确认开篇后保存，保留原有语义。
- 提交包含校验、重复提交保护和错误后保留输入。风格与模板信息纳入服务端及备份校验，旧作品与旧备份兼容。

自动浏览器目测仍受已保存的权限规则限制；组件、接口、文字对比度与构建验证不替代视觉验收。

验证：完整 npm test、最终创建流程专项、构建和文字对比度检查通过；临时 API 已验证风格／模板往返及旧数据兼容。测试不调用真实模型、不发送验证码。
