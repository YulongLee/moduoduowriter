# 墨多多写作

围绕小说、文字剧本与内容编辑的本地创作应用，包含可编辑的作品、工作流、拆书和投稿记录，以及可配置的 AI 服务接口。当前界面采用浅色稿纸、墨绿品牌与蓝／紫／暖金功能辅助色，配合原创绘画书封，首页、作品库、小说与剧本工作台、编辑器使用统一视觉规范。

当前范围：按用户最新决定，视频相关功能暂缓。漫剧工坊、分镜入口与图片／视频生成已收起，后台媒体调用与查询停用；小说、文字剧本、拆书及编辑流程继续开放，已有分镜资料保留。

## 代码仓库

统一在 [YulongLee/moduoduowriter](https://github.com/YulongLee/moduoduowriter) 维护。

```sh
git clone git@github.com:YulongLee/moduoduowriter.git
cd moduoduowriter
npm ci
npm run dev -- --port 5173
```

仓库仅包含代码、依赖锁文件和项目文档。本机 `.local` 中的模型密钥、OSS 凭证、账号、数据库与文稿，以及 SSH 私钥、依赖目录和构建产物均不提交。首次克隆后，在本机管理页 `http://127.0.0.1:5173/#service-admin` 配置服务；没有配置时可使用示例体验。

提交代码前运行 `npm test` 与 `npm run build`。常规回归使用受控响应，不调用付费模型；`scripts/live-flow.mjs` 是显式付费联通验证，不纳入常规回归。

## 本地运行

建议 Node.js 24 或以上版本（最低 22.13），已在本机 Node.js 25.2.1 验证。

```sh
npm install
npm run dev -- --port 5173
```

打开 http://127.0.0.1:5173/ 。`npm run build` 后可使用 `npm run preview`，预览服务同样加载本地 API。静态托管单独的 `dist/` 不包含后端接口。

- **作品管理**：创建、搜索、筛选、排序、卡片与列表切换，修改名称、题材、类型、简介和封面；移入回收站及恢复。
- **TXT 导入与导出**：识别中文章节或 Chapter 标题自动分章，保留序章；导出完整作品正文。
- **写作编辑器**：章节标题与正文、大纲、人物资料、章节添加、排序、删除，字号调整与专注模式。
- **章节版本**：手动保存、删除前备份、AI 正文采纳前备份、历史预览与确认恢复；删除的章节也能从版本恢复。每部作品保留最近 12 份版本，并对旧版本按 50 万字符滚动清理。
- **AI 创作入口**：一键总纲、人物与开篇；八类写作工具；编辑器续写、润色、审稿与灵感；候选可预览、修改、追加或替换，最近一次采纳可撤销。
- **章节规划**：结合总纲、人物及已有章节生成章纲；逐项编辑、移除，确认后创建带规划的空白章节，保留原有正文。
- **工作流**：传入此前结果及关联原作，用户确认后继续；自动保存草稿，关闭后可接着做；修改前序结果会使下游缓存失效。编辑优化固定引用所选章节，可预览后写回原章节，也可保存为新作品。
- **生成记录**：保存真实请求、结果、失败原因及返回的 tokens，界面不显示底层模型；可恢复文本、创作规划、章纲、拆书及分镜，也可主动重新生成。原请求重试使用幂等编号，防止同一请求重复提交。
- **账号与恢复**：首账号接管既有空间并成为管理员；后注册作者使用独立文稿、记录、备份目录和服务端账本。密码使用加盐哈希，支持一次性恢复码与换码，重置会注销旧会话；管理连接接口仅管理员可用。
- **小说拆书**：导入、粘贴或选择已有作品，选择四类维度；真实统计、AI 分析或示例观察框架；个人笔记、保存、重新打开、删除和导出。
- **视频相关功能（暂缓）**：当前版本关闭漫剧、分镜和图片／视频生成入口，以及后台媒体请求和查询；既有代码与资料保留，不影响文字剧本创作。
- **投稿记录**：关联作品、自定义平台、实际日期、反馈备注，更新投递/沟通/签约等状态，筛选、编辑、删除及导出包含简介和正文的投稿包。
- **备份恢复**：作品（含回收站、版本、资料库和正文队列）、收藏、拆书、工作流、历史分镜、投稿、创作草稿和人工评估共八类资料可整库导出 JSON、校验后合并导入；作品冲突保留为副本。不含账号、生成记录、媒体文件、密钥与演示账本。
- **本机磁盘备份**：原作者空间保存到项目 `.local/workspace.json`，新账号使用 `.local/users/<空间编号>/workspace.json`，保留前一个磁盘快照；用修订号阻止另一窗口的旧快照覆盖新备份。
- **会员与墨点**：真实 App 使用服务端保存的演示账本，包含规范价格订单、额度预留、幂等结算与失败退回，不收款；浏览器中的数字不能覆盖服务端余额。

## 后台管理平台

独立后台入口为 `http://127.0.0.1:5173/#admin`，包含运营概览、用户管理、生成记录、演示订单账本、AI/登录服务配置及操作日志。原 `#service-admin` 地址作为服务配置别名保留。管理员在创作工作台账号菜单也可进入；后台不加载作者个人文稿、账本或缓存，普通作者不可访问管理接口。

管理员凭据仅按本地初始化设置，不写入仓库、不在应用启动时重置。维护脚本 `scripts/provision-admin.mjs` 通过标准输入接收资料，先备份 SQLite 再初始化并验证登录；给旧管理员增加邮箱别名时保留用户名和原作品空间。如果邮箱已属于普通作者，则拒绝自动提升。初始化会使目标管理员的旧密码、恢复码和会话失效。

用户停用会撤销会话，并阻止密码、验证码和微信登录；文稿保留，重新启用后需重新登录。后台生成与订单列表只提供管理元数据，不回传创作正文、提示词和密钥。订单依然是演示账本。详见 [后台管理平台与验收](./后台管理平台与验收-2026-10-28.md)。

## 三种登录方式

## 接通真实 AI

维护者直接打开本机管理页 `http://127.0.0.1:5173/#service-admin`。该入口不放入普通导航；原有本机账号与接口访问限制继续适用。

1. 填写服务商的接口基础地址（公开 HTTPS 地址）、模型 ID 和 API 密钥。
2. 国内常见兼容接口使用 **Chat Completions 兼容**；OpenAI 可使用 **Responses**。
3. 若服务商支持 JSON 输出模式，可勾选该项；应用仍会验证结构化结果的字段与内容。
4. 点击「保存配置」，再「测试已保存配置」。测试会发送一句测试文本，可能产生服务商费用。
5. 返回创作页面，在「创作与数据设置」中选择「智能创作」。也可以在管理页将默认创作方式设为「智能创作」，供无明确偏好的浏览器使用。

密钥保存在项目 `.local/ai.json`（仅当前用户可读写），不会放进浏览器 localStorage、前端构建或整库备份。本机管理接口返回技术配置和是否已保存密钥，不回传密钥正文。普通客户端改读 `/api/service/status`，仅返回配置是否齐全及默认创作方式，不读取模型、接口地址、协议或密钥状态。生成、幂等重试和历史接口均移除模型字段，本机数据库保留内部元数据。密钥留空会保留旧值，可勾选清除。

真实生成使用当前需求、大纲、人物、正文及工作流前序结果。生成时把所选内容发送给你配置的服务商。支持取消、90 秒超时、并发限制、错误提示和重试；错误或格式不完整不会冒充成功，也不会自动写入文稿。当前单次上下文上限约 6.5 万字符，长篇请按章节或片段处理。

**2026-10-22 已使用用户提供的阿里云配置完成真实联通验证。** 当前默认模型为 `deepseek-v4.1-flash-1017`，使用百炼兼容接口、JSON 模式和非思考模式；无明确示例偏好的浏览器会默认使用真实 AI。除此前开篇及结构化规划外，本轮已通过应用接口实测八类工具、章节规划、拆书和分镜，共 11 次文本请求、3,896 tokens。原接入验证见 `.local/integration-check.json`，本轮流程与限制见 `.local/qa/完整流程验证.json`。常规自动化测试使用受控响应，不消耗模型额度。

接口格式参考 [OpenAI 文本生成文档](https://developers.openai.com/api/docs/guides/text) 与 [结构化输出文档](https://developers.openai.com/api/docs/guides/structured-outputs)。Chat Completions 使用兼容服务常见的 `max_tokens` 参数；新 OpenAI 模型建议选 Responses。

## 阿里云 OSS

「创作与数据设置」包含 OSS 备份区。已接通用户的上海 Bucket，使用独立前缀 `materials/moduoduo-writing`，不会操作其他项目目录或修改 Bucket ACL。

- 凭证仅保存在本机 `.local/oss.json`，配置接口不回传 AccessKey ID 或 Secret。
- 连接测试创建一个私有小文件，验证上传、读回、私有 ACL 和列举，再删除测试文件。
- 点击「备份到 OSS」上传作品及创作资料（不含账号、生成记录、媒体文件、密钥与模拟账本），创建全新的私有对象，读回并校验 SHA-256 后报告成功。
- 备份记录可按页浏览，服务端只允许读取该应用的备份目录。
- 恢复会先读回并校验数据，再由用户确认合并；作品冲突保留为副本。
- 不会自动把浏览器中的文稿上传到云端。每次备份上限 20MB。

已经完成真实 OSS 私有文件、空白备份及独立测试文稿的上传、校验、列举、恢复与清理；验证用的测试对象均已删除，没有上传用户现有小说。详情见「阿里云接入说明.md」。

## 本地数据和服务边界

作品、收藏、拆书、工作流、分镜、投稿、创作草稿与人工评估自动保存到本机 `.local/studio.sqlite`，浏览器保留即时缓存。首次打开自动迁移已有浏览器资料；后续优先加载服务端数据。编辑采用修订号校验，多窗口同时修改同一记录会保留冲突副本。运行中服务连接中断时保留缓存与待同步标记，恢复连接后重试保存。

当前服务默认绑定本机。账号支持多个独立空间与管理员/作者角色，原密码账号仍依靠作者保存的恢复码重置密码；新增验证码登录与绑定不会自动找回或合并旧账号。登录会话和生成记录也保存在 SQLite，服务重启后保留；中断的文本任务不会自动重发，已取得服务商编号的视频任务会继续查询。

设置可主动执行 JSON、磁盘快照或 OSS 备份，备份范围为八类创作资料。快照不等于多设备实时同步，账号、生成记录与媒体文件需单独管理。删除整个项目的 `.local` 目录会丢失本机数据库与配置。

首个账号为管理员，既有单账号迁移后保留管理员权限；后续账号为作者。管理页和连接配置接口实施角色校验，普通作者不能管理服务连接。

本地 API 默认仅允许 localhost/127.0.0.1 地址并校验请求来源；仅在维护者显式配置 `MDD_PUBLIC_ORIGIN` 后额外接受该正式 HTTPS 来源，登录后的空间标头与会话不一致会拒绝请求，开发服务禁止提供 `.local`、环境变量与证书文件。`.gitignore` 排除密钥和本机数据目录。请勿把此本地服务直接作为公开多用户后台。

以下仍需服务条件或正式上线建设：公网账号部署与跨设备实时同步、真实支付渠道配置、百炼图像/视频模型权限、向外部平台自动投递。服务端演示订单与额度结算已经实现。真实模式下的模型费用由服务商账户收取；墨点始终是演示金额。
